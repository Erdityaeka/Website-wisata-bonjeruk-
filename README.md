# 🌿 Bonjeruk Village Tourism Website

A digital tourism information platform developed to introduce and promote Bonjeruk Tourism Village. This website provides information about the village profile, culinary destinations, social media channels, contact information, and tourism locations in a simple and accessible way.

## 🔗 Live Demo

🌐 Website: https://desa-wisata-bonjeruk.web.app/

---

## 📖 About The Project

Bonjeruk Village Tourism Website was developed as part of a village digitalization initiative. The application serves as an information center for visitors who want to discover local tourism attractions, culinary destinations, and social media information related to Bonjeruk Village.

### Main Features

- 🏘️ Village Information
- 📍 Culinary Tourism Locations
- 📞 Contact Information
- 🌐 Social Media Integration
- 🖼️ Tourism Destination Details
- 📱 Responsive Mobile-Friendly Design
